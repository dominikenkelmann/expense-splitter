# FairSplit — Expense Splitter (UCDD Reference App)

A reference implementation demonstrating **Use Case Driven Development (UCDD)** in TypeScript with Clean Architecture and strict test traceability.

---

## Overview

FairSplit is a lightweight, zero-friction group expense management application designed to track shared costs and compute optimal debt settlement paths with minimal transactions.
