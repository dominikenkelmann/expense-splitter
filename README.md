# FairSplit

A sample group expense management web application demonstrating Use Case Driven Development (UCDD) with TypeScript and Clean Architecture.

This repository serves as the companion sample project for an upcoming blog post *(link will be added once published)*.

## Prerequisites

Make sure you have [Node.js](https://nodejs.org/) (v18 or higher recommended) and `npm` installed.

## Getting Started

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Start the development server:**
   ```bash
   npm run dev
   ```

3. Open your browser at the local URL shown in the terminal (typically `http://localhost:5173`).

## Other Commands

- **Run tests:** `npm test`
- **Build for production:** `npm run build`
